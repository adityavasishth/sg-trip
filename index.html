This app saves expenses to a GitHub repo. It needs an access key once per phone. If someone sent you the full trip link, just open that link instead, and you're in.

How to make the key (Aditya only)
  1. On GitHub: Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Name: sg-trip. Expiration: 30 days.
  3. Repository access: Only select repositories → sg-trip.
  4. Permissions → Repository → Contents: Read and write.
  5. Generate, copy it, paste it above, then go to People → Copy share link and post that link on WhatsApp.
